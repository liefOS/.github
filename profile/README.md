# About liefOS and its story

liefOS (pronounced: layf-Oh-Es, stylized with lowercase "I' on the first letter. Short for Liejan's Fluid Operating System (lie - Liejan, f - Fluid + OS), quite complicated isn't it.) is a virtual simulated mobile operating system for desktop made using JavaScript, Node.js, and other web technologies. There's really no goal of liefOS here. It's a project I, Liejan, made for fun to fulfill my dreams of making my own operating system and designing it easily. liefOS was made for fun and to pass the time but eventually became my hobby
and passion.

A concept I drew on a paper back then around 2019-2020 showcased a simple elements of what my preferred operating system looks like (I was already addicted to tech-related contents when I was a kid), It didn't look good... When I finally got a laptop to start actually coding. liefOS' first actual prototype was then made in late-2023, It featured a simple Ul concept of what I was planning back then. It was published to blogger/blogspot for a whole week until I decided to take it down. There are already 10+ prototypes I made.
With different codenames. And now I have finally settled with this one.

What makes liefOS unique than other web-based operating system is that it doesn't just simulate an interface without real features, It also isn't an operating system running on the cloud, It's a mobile-like web operating system for desktop users, because seriously why have a desktop web-OS when you're already on a desktop. liefOS is a unique mobile web-based operating system that runs on top of your existing operating system (as it's not a real operating system) and has actual features that you can use rather than just being a mockup concept UI. It features an advanced file system (LFS) that's really capable, It also supports User Data Snapshots. A custom programming language (LAPL) with custom app formats (LAPP), and more. It is also designed to be fluid, and feels alive.
Every little click, hover, and interaction is animated to satisfy you. It is designed to be a fluid and clean experience.
